  语音包说明 —— 自定义学伴音色与离线语音包
════════════════════════════════════════════════════════════════

【放置位置】
把一个名为 voice.txt 的文本文件放进对应学伴的形象目录：

  static/assets/character/default/voice.txt    → 思小诘（苏格拉底问答法）
  static/assets/character/feynman/voice.txt    → 费小曼（费曼学习法）
  static/assets/character/gewu/voice.txt       → 格小致（格物致知）
  static/assets/character/spaced/voice.txt     → 温小习（间隔复习法）
  static/assets/character/sq3r/voice.txt       → 阅小思（SQ3R 阅读法）
  static/assets/character/retrieval/voice.txt  → 检小索（检索练习法）

【文件格式】
文件里只写一行音色 ID，例如：

  zh-CN-yunxiaNeural

保存后重新打开"新的学习"弹窗即生效（无需重启程序）；
删除 voice.txt 即恢复该学伴的默认音色。

【查看全部音色】
微软会不定期上架/下架音色，以实时列表为准：
  .venv\Scripts\python.exe -m edge_tts --list-voices
注意：晓辰(xiaochen)、晓墨(xiaomo) 已被微软下架，写了会合成失败。

【容错说明】
音色 ID 写错或文件为空时，自动回退该学伴的默认音色；
离线场景会降级为系统本地语音（无法区分音色，属正常现象）。
方法选择卡片上每个学伴都有"🔊 试听"按钮，可以先听后选。

【离线语音包（进阶）—— 完全离线、不吃联网音色】

想让某个学伴在断网时也用自己的专属声音？给它放一个离线语音包。

【学伴目录对照】
  static/assets/character/default/    → 思小诘
  static/assets/character/feynman/    → 费小曼
  static/assets/character/gewu/       → 格小致
  static/assets/character/spaced/     → 温小习
  static/assets/character/sq3r/       → 阅小思
  static/assets/character/retrieval/  → 检小索

【模型下载】
sherpa-onnx 官方 TTS 模型发布页（免费、可离线）：
  https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models
中文示例（拼音女声，约 130MB）：
  vits-piper-zh_CN-huayan-medium.tar.bz2
同页面还有其他中文 vits 模型（huayan/meilin/icefall-aishell3 等，
多说话人模型默认取第 1 个音色）。

【放置方法】
1. 在学伴目录下新建 voice 子目录，例如：
     static/assets/character/spaced/voice/
2. 把下载的压缩包解压后里面的全部文件都放进去，典型包括：
     *.onnx（模型本体，必需）
     tokens.txt（必需）
     espeak-ng-data/ 文件夹（piper 格式才有）
     lexicon.txt / dict/ 文件夹（词典格式才有）
3. 放下即用，无需重启程序；删除 voice 目录即恢复在线音色。

【优先级说明】
edge-tts 在线音色（音质最佳，需联网）→ 系统本机语音 → 学伴离线语音包（最后兜底）：
只有断网且系统语音也不可用时才会用到离线包；
包损坏或未安装 sherpa-onnx 时跳过离线包，朗读不受影响。

────────────────────────────────────────────────────────────────

【语音输入（离线识别）—— 🎤 说的话变文字】

输入栏左侧的 🎤 是语音输入按钮：点击开始说话，说完再点一次，
识别出的文字会填进输入框（可修改后手动发送）。识别完全在本地进行，
不联网、不上传任何音频。

【模型下载（首次使用需一次，约 230MB）】
sherpa-onnx 官方 ASR 模型发布页：
  https://github.com/k2-fsa/sherpa-onnx/releases/tag/asr-models
下载（中英混合识别，推荐）：
  sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17.tar.bz2
GitHub 连不上时可用 HuggingFace 国内镜像分别下载这两个文件：
  https://hf-mirror.com/csukuangfj/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17/resolve/main/model.int8.onnx
  https://hf-mirror.com/csukuangfj/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17/resolve/main/tokens.txt

【放置方法】
在项目根目录（打包版为安装目录）下新建 models/asr/ 文件夹，
把解压出来的这两个文件放进去：
  model.int8.onnx
  tokens.txt
无需重启程序，放下即可使用；删除即回到"未配置"状态。

【未配置模型时】
点 🎤 录音后，应用会提示"语音识别模型未配置"。
麦克风权限被系统/应用拒绝时也会提示，请到系统设置中允许。
